# Custom C++ Game Engine
 ⚠️ This project is under active development and may change significantly over time.

A custom game engine built from scratch in C++ with OpenGL, focusing on low-level rendering, math, and editor tooling.

## Features
- Rendering Pipeline (OpenGL)
- Camera System (View / Projection)
- Player Controller
- Mouse Raycasting (Screen → World)
- Entity System
- Axis-Aligned Bounding Box (AABB) Collision & Ray Intersection
- Custom Math Library (Vec3, Mat4, Ray, Geometry)
- Input System (Keyboard & Mouse)
- In-Editor Object Manipulation (Gizmos - Work in Progress)

## Tech Stack
- C++
- OpenGL
- GLFW
- Custom Math Library
- ImGui (planned / WIP)
